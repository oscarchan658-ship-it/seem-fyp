# Group T 第一學期成果解讀與示範指南

## 先理解你們在研究什麼

正式題目保留 **Sentiment Analysis for Depression Detection**，本學期可證明的主線是：情緒模型能否分類一般語氣，以及對話系統能否把回答整理成「由使用者確認的症狀頻率」。情緒負面不等於症狀出現得頻密；問卷分數也不能替代臨床診斷。兩條線在同一個介面整合，但計分只讀取八個確認答案。

## 三種證據要分開

1. **公開資料實驗**：TweetEval 原始 train / validation / test。TF-IDF + LR 與 SVM 都遠高於 majority。SVM 是按 validation 選出，不是看 test 挑最好。test macro-F1 0.5607，並非「56% 抑鬱辨識率」。負面類別 recall 只有 0.450，值得討論漏判為 neutral 的問題。
2. **自編診斷案例**：64 個 parser 案例和 48 個 Terra 句子都是 AI 協助編寫，沒有獨立人工 gold。可以展示特定錯誤和覆蓋率，不能宣稱代表真實使用者。規則系統接受率 37.5%，所以「接受的全對」不代表全能理解。
3. **軟體測試**：最新版 223 項全部通過（舊版 207 項及 84% coverage 另存歷史紀錄），檢查確認、修改、清除、分數邊界及 API 異常。不是 207 位參與者，也不是臨床驗證。

Terra 的 48 次呼叫只有 46 次成功。成功案例都符合自編標籤，但不應刪掉 2 次失敗；有效回應延遲中位數約 12 秒。API 是使用者指定的第三方相容服務，模型身分只按服務端回報記錄。

## 5 分鐘示範

先按 README 啟動網頁。全部使用虛構資料。

1. 側欄選「繁體中文」或「English」，開始虛構對話。用自然語言描述過去兩星期，例如睡眠不好和疲倦，不需要逐題填表。
2. 可一次說幾件事；AI 會整理候選並追問缺少的資料。模糊的「有時」不應直接變成分數。
3. 補充其他症狀的頻率，並試說「剛才睡眠講錯，是六晚，不是十晚」。觀察摘要和來源引句是否更新。
4. 八項清楚後按「核對整理內容」，檢查原句、摘要與選項；可改選項，再勾選確認計分。實機英文與中文示範的候選均為 [0,1,1,2,0,0,1,0]，總分 5/24，這只是一組虛構例子。
5. 可切換語言，已有對話和分數保留；舊原句不翻譯。AI 後續回覆使用所選語言。API 失敗時按「重試上一句」，不要把連線失敗當作零分。
6. 另開測試對話輸入 `[DEMO_INTERRUPT]`，可看到示範中斷及清除。這不是真實危機偵測。

舊版逐題問卷仍在 `questionnaire_app.py`，用於規則診斷與離線基線。新版架構是：對話 → mock guard → 帶上下文的模型提議 → 欄位及引句驗證 → 使用者核對 → 純計分函式。引句存在不代表理解必然正確，沒有獨立標註的新版多輪準確率。

## 文獻怎樣支持設計

- Kroenke 2009：PHQ-8 的背景，這次只讀到 indexed abstract，不能假裝完整閱讀。
- Dhingra 2011：天數轉 ordinal 的來源；一天仍需在 UI 保留原始意思。
- TweetEval 2020：可重現 split 與 sentiment 評估；官方指標是 macro recall，也另外報 macro-F1。
- Laranjo 2018、Woebot 2017：健康對話研究的設計及限制，不是我們系統有效的證據。
- Selective Classification、Calibration：為什麼要同時報覆蓋率和錯誤，也不能把 confidence 當正確機率。
- DAIC、GoEmotions：理解資料範圍；資料集存在不等於已取得授權或完成訓練。

每篇的閱讀段落、方法、限制與設計影響見 `literature/reading_matrix.md`，內容抽取見 `literature/source_text`。正式報告有 9 篇閱讀研究、1 項原資料集出處及 2 項 API 技術文件。

## 下學期具體順序

- 第 1–2 週：第二位組員重跑現有實驗，凍結問題文字與語言範圍，處理已知 bugs。
- 第 3–5 週：取得並檢查原 96-case 候選集；兩位獨立標註、仲裁，按模板／情境分組切分，避免同模板洩漏。
- 第 6–8 週：比較 rule 與一個 structured NLU；固定 prompt，保留 failure，報 coverage、wrong acceptance、abstention、修正次數。
- 第 9–10 週：若研究要求及審批容許，才進行小型互動評估；控制內容並分開比較固定問句、上下文對話與情緒回覆的效果。
- 其後：只有取得適當授權資料才做 sentiment / context / fusion 的 depression-label 研究；否則以現有主線完成，不捏造 depression accuracy。

這些是建議時程，不是導師已批准的承諾。正式 E1/E2/E3 的舊工具和 synthetic rehearsal 保留，但不能搬進「已完成實驗」章冒充新結果。
