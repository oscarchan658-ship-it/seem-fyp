# V3.2 研究準備與待審證據

## C24 FMEA 初稿

分級先按影響排序。H 為提前／錯誤計分或中斷被繞過，M 為研究結果失真、流程停滯或人工重做。發生率與可檢知性保留未知，待團隊核定量尺及實測資料。下列關係用於安排測試。

| 失效模式 | 影響／級別 | 控制與檢查 | 責任／殘餘風險 |
|---|---|---|---|
| Guard 覆核、中斷或異常時，確認先計分 | H，產生不應顯示的結果 | T23／T29／T36，C23／C27；同批按鈕延後處理，守門故障阻斷 | Systems；框架在送達前可合併同元件輸入，真實辨識仍未知 |
| 舊版確認提交 | H，修改後顯示舊分數 | T07／T20／T28，C10；會話與版本綁定，確認後以八題快照計分 | Systems；需重跑新確認策略 |
| 約略天數被直接轉成分數 | H，錯誤候選影響篩查 | C06／C08；天數先保留為未計分證據，映射待核定 | Systems 與導師；待核定全部邊界 |
| 改寫跨資料集合 | M，高估模型結果 | C11；群組分割、正規化去重及標註者複核 | Dataset owner；語義近似須人工檢查 |
| 政策使用不同後續回應 | M，政策差異混入資料影響 | C19；凍結人工 Oracle 分支，缺分支單列 | 研究小組；完整分支及樣本量待審 |
